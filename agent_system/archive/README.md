# archive/ — 退避コード置き場

ここには **現在は使用していない** 実装を退避しています。
削除ではなく退避なので、将来必要になったときに参照・復元できます。

## 重要な約束

- このディレクトリのコードは **稼働コードから一切 import しません**
  (tests/test_no_api_dependency.py が機械的に検証しています)
- このディレクトリのコードを復元・有効化する判断は **必ず人間が行います**。
  自動で有効化される経路は存在しません

## api_based/ — 外部モデル呼び出し版(課金が必要)

初期実装で使っていた、外部モデルをコードから呼び出す構成一式です。

| ファイル | 内容 |
|---|---|
| `llm_client.py` | 外部モデル呼び出しクライアント + 動作確認用スタブ |
| `safety.py` | 呼び出しエラーの例外階層・リトライ・フォールバックチェーン |
| `base.py` | 役割エージェントの共通呼び出し処理 |
| `config.py` | 役割ごとのモデルルーティング設定 |
| `requirements.txt` | 当時の依存パッケージ定義 |

### 復元する場合(人間の確認が必須)

この構成を復元すると **従量課金(トークン課金)が発生します**。
復元前に以下を人間が確認・承諾してください。

1. 従量課金が発生することを理解し、予算上の承認を得たか
2. 現行プランの範囲を超える契約(従量課金の有効化など)が必要になることを確認したか
3. 機密情報(顧客情報・認証情報)を外部に送信しない運用ルールを整備したか

確認できた場合のみ、ファイルを元の場所(core/ / agents/)に戻し、
依存パッケージを導入した上で、tests/ の非依存チェックを意図的に緩和してください。
このディレクトリ内のコードは退避時点のスナップショットであり、
そのままでは動作しません(稼働コード側の構成が変わっているため)。
